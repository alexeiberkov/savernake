# Осенний лес — правила и игровая логика

## 1. Общая идея игры

Каждый игрок строит собственный лес из квадратных карточек.

В лесу находятся:

- карточки тропинок;
- карточки животных.

Животным нужна еда. Еда изображена на тропинках.

Задача игрока:

1. размещать животных;
2. прокладывать от них тропинки;
3. собирать подходящую животным еду;
4. улучшать животных при помощи бонусов;
5. получить как можно больше победных очков.

В стандартной игре лес каждого игрока ограничен размером:

4 × 4 карточки

То есть в конце игры лес содержит 16 карточек.


# 2. Типы карточек

## 2.1. Карточка тропинки

Карточка тропинки содержит участок дороги через лес.

На тропинке могут находиться символы еды:

- ягоды;
- червяки;
- яйца;
- орехи.

Тропинка может продолжаться через несколько карточек.

Одна непрерывная линия от животного считается одной тропинкой.


## 2.2. Карточка животного

Карточка животного содержит:

- изображение животного;
- начало его тропинки;
- вместимость норы;
- количество победных очков за само животное;
- четыре вида еды;
- стоимость каждого вида еды в победных очках.

Пример структуры:

```
Animal:
    name
    baseVictoryPoints
    burrowCapacity
    foodValues:
        berries
        worms
        eggs
        nuts
    pathExit
```

Важно:

разные животные получают разное количество очков за одну и ту же еду.

Например, яйца могут быть очень ценными для одного животного и практически бесполезными для другого.


# 3. Начальная подготовка

Карточки животных и карточки тропинок перемешиваются отдельно.

Создаются две отдельные колоды:

- Animal Deck;
- Path Deck.

Каждый игрок получает одну случайную карточку животного.

Эта карточка кладётся перед игроком лицевой стороной вверх и является первой карточкой его леса.

Карточку можно повернуть перед размещением.

Каждый игрок получает собственный маркер подсчёта победных очков.

Определяется первый игрок.

Первый игрок получает специальный маркер первого игрока.


# 4. Центральное игровое поле

На центральном поле есть четыре позиции выбора карточек.

Каждая позиция связана с одним животным-помощником:

1. Петух
2. Броненосец
3. Козлик
4. Кролик

В начале каждого раунда возле поля выкладываются четыре карточки.

Возле позиции Кролика всегда находится:

- 1 карточка животного.

Возле остальных трёх позиций:

- по 1 карточке тропинки.

Итого:

- 1 Animal card;
- 3 Path cards.


# 5. Раунд

Игра состоит из нескольких раундов.

Игроки ходят по часовой стрелке, начиная с владельца маркера первого игрока.

В течение раунда каждый игрок делает один ход.

В свой ход игрок обязан:

1. выбрать одну доступную карточку;
2. забрать её;
3. добавить карточку в свой лес;
4. получить бонус позиции, возле которой находилась карточка.

ВАЖНО:

После того как игрок забрал карточку, пустое место НЕ заполняется новой карточкой.

Поэтому следующий игрок выбирает уже из меньшего количества вариантов.

Например:

Игрок 1 выбирает из 4 карточек.
Игрок 2 — из 3.
Игрок 3 — из 2.
Игрок 4 получает последнюю карточку.

Если игроков меньше четырёх, после завершения раунда оставшиеся карточки сбрасываются.


# 6. Размещение карточки

Взятая карточка обязательно добавляется в лес игрока.

Перед размещением её разрешается вращать.

Карточка должна соприкасаться стороной минимум с одной уже находящейся в лесу карточкой.

Диагональное касание не считается соединением.

Правильно:

```
[X][NEW]

или

[X]
[NEW]
```

Неправильно:

```
[X][ ]
[ ][NEW]
```


# 7. Ограничение размера леса

Стандартный лес не может выходить за размеры:

4 × 4.

Игрок может постепенно формировать этот квадрат в любом направлении, однако итоговое расположение всех карточек должно помещаться в прямоугольник 4 × 4.


# 8. Тропинки

Тропинка — непрерывная линия, начинающаяся на карточке животного.

Она может:

- проходить через несколько карточек;
- поворачивать;
- изгибаться;
- заканчиваться тупиком.

Игрок НЕ обязан соединять новый участок тропинки с уже существующим.

Тупики разрешены.


## Запрещено

Тропинка не может:

- разветвляться;
- пересекаться с другой тропинкой.

То есть одна линия всегда должна оставаться одной непрерывной неразветвляющейся линией.


# 9. Животные и тропинки

Каждое животное использует тропинку, начинающуюся непосредственно с его карточки.

На одной тропинке в итоговом лесу может находиться только одно животное.

Если в процессе строительства получилось, что два животных оказались на одной тропинке, это временно допустимо.

Но перед финальным подсчётом очков игрок должен оставить на этой тропинке только одно животное.

Остальные животные сбрасываются.

Сброшенные животные не приносят никаких очков.


# 10. Сбор еды

На тропинках встречаются символы четырёх видов еды:

BERRIES
WORMS
EGGS
NUTS

Животное получает еду только со своей собственной непрерывной тропинки.

Еда учитывается начиная от животного и далее вдоль тропинки.

Количество еды ограничивается вместимостью норы животного.

Пример:

burrowCapacity = 3

На тропинке находится:

worm
worm
egg
nut

Животное сможет учесть только первые 3 символа еды:

worm
worm
egg

Четвёртый символ уже не помещается в нору.


# 11. Вместимость норы

Каждое животное имеет параметр:

burrowCapacity

Он определяет максимальное количество символов еды, которые животное может использовать для финального подсчёта.

Например:

capacity = 5

означает, что животное может получить очки максимум за пять символов еды со своей тропинки.


# 12. Бонусы игрового поля

Карточка, которую выбирает игрок, связана с одним из четырёх животных-помощников.

Игрок получает соответствующий бонус.


# 13. Петух

BONUS:

получить маркер первого игрока.

Если игрок выбирает карточку возле Петуха, маркер первого игрока сразу переходит к нему.

Этот игрок будет начинать следующий раунд.

Маркер также приносит:

+1 победное очко

в конце игры.

Если за весь раунд никто не выбрал карточку возле Петуха, маркер остаётся у текущего владельца.


# 14. Броненосец

BONUS:

+1 к вместимости норы одного животного.

Игрок получает жетон норы.

Жетон размещается на карточке одного из животных игрока.

После этого:

animal.burrowCapacity += 1

Пример:

было capacity = 3
стало capacity = 4

Это позволяет животному учитывать ещё один символ еды со своей тропинки.


# 15. Козлик

BONUS:

улучшить ценность одного вида еды для одного животного.

Игрок получает жетон воды.

Жетон кладётся на один из четырёх углов карточки животного, рядом с выбранным символом еды.

После этого стоимость этой еды для конкретного животного увеличивается на 1 победное очко.

Пример:

до бонуса:

eggs = 2 VP

после жетона воды:

eggs = 3 VP

Этот бонус применяется ко ВСЕМ собранным этим животным символам выбранного вида еды.

Например:

animal collected 3 eggs
eggValue = 2
waterBonus = +1

score:

3 × (2 + 1) = 9 VP

На каждый угол карточки животного можно положить максимум один жетон воды.


# 16. Кролик

BONUS:

получить новое животное.

Позиция Кролика является единственным способом получить дополнительные карточки животных.

Поэтому возле Кролика в начале каждого раунда выкладывается карточка животного.

Игрок, выбравший эту карточку, добавляет нового зверя в свой лес.

Карточку животного разрешается вращать перед размещением.


# 17. Конец раунда

Раунд заканчивается после того, как каждый игрок сделал один ход.

Если возле поля остались невыбранные карточки, они сбрасываются.

После этого формируется новый набор:

```
Rabbit:
    1 Animal card

Other helper slots:
    3 Path cards
```

Первым ходит игрок, у которого находится маркер первого игрока.


# 18. Конец игры

Стандартная игра заканчивается после того, как каждый игрок полностью построил лес:

4 × 4

то есть:

16 карточек.

После этого выполняется финальная проверка тропинок.

Если на одной тропинке находятся два или больше животных:

- игрок выбирает одно;
- остальные сбрасываются.

Сброшенные животные не участвуют в подсчёте очков.


# 19. Подсчёт победных очков

Каждое оставшееся животное приносит очки из двух источников:

1. базовые очки за карточку животного;
2. очки за собранную еду.


## Формула животного

```
animalScore =
    baseVictoryPoints
    +
    foodScore
```


## Очки за еду

Для каждого символа еды учитывается стоимость, указанная именно на карточке этого животного.

Например:

```
foodValues:
    berries = 0
    worms = 1
    eggs = 2
    nuts = 1
```

Если животное собрало:

```
berries = 1
worms = 2
eggs = 2
nuts = 0
```

то:

```
foodScore =
    1 × 0
    + 2 × 1
    + 2 × 2
    + 0 × 1

foodScore = 6
```


# 20. Влияние жетонов воды

Если возле символа еды находится жетон воды:

```
effectiveFoodValue =
    baseFoodValue + 1
```

Например:

worms value = 1
water token on worms

effective worms value = 2


# 21. Полный счёт игрока

```
playerScore =
    sum(all valid animal scores)
    +
    firstPlayerBonus
```

где:

firstPlayerBonus = 1

если игрок закончил игру с маркером первого игрока.

В остальных случаях:

firstPlayerBonus = 0


# 22. Победа

Игрок с наибольшим количеством победных очков выигрывает.

При ничьей преимущество получает игрок, который сидит ближе остальных к владельцу маркера первого игрока по порядку хода.

Сам владелец маркера первого игрока считается первым в этом порядке.


# 23. Продвинутый режим для двух игроков

Для двух игроков существует специальный более сложный режим.

Основные отличия:


## Размер леса

Вместо:

4 × 4

каждый игрок строит:

8 × 4

или

4 × 8.

Всего:

32 карточки.


## Начальные животные

Каждый игрок начинает не с одного, а с двух случайных животных.

Обе карточки размещаются рядом друг с другом.

Перед размещением каждую можно вращать.


## Ходы

В каждом раунде каждый игрок получает по две карточки.

Последовательность выбора:

```
Player A
Player B
Player A
Player B
```

То есть первый игрок выбирает:

1 карточку;

затем соперник:

1 карточку;

затем первый:

ещё 1 карточку;

и соперник получает последнюю.

# 25. Последовательность хода в коде

Псевдологика:

```
function playerTurn(player):

    availableCards = getAvailableMarketCards()

    selectedCard = player.selectCard(availableCards)

    helper = selectedCard.marketSlot.helper

    player.placeCard(selectedCard)

    applyHelperBonus(player, helper)

    removeCardFromMarket(selectedCard)

    passTurn()
```

ВАЖНО:

market НЕ пополняется после каждого хода.


# 26. Завершение раунда

```
function endRound():

    discardRemainingMarketCards()

    fillMarket():
        Rabbit -> Animal card
        Other slots -> Path cards

    currentPlayer =
        ownerOfFirstPlayerMarker
```


# 27. Проверка размещения карточки

При попытке разместить карточку нужно проверить:

1. карточка касается стороной хотя бы одной существующей карточки;
2. карточка не занимает уже занятую клетку;
3. весь лес остаётся внутри разрешённого прямоугольника;
4. размещение не создаёт запрещённого пересечения тропинок;
5. размещение не создаёт разветвления тропинки.


При этом НЕ требуется:

- чтобы новая тропинка соединялась со старой;
- чтобы все участки дороги были соединены;
- чтобы тропинка обязательно продолжалась.

Тупики являются валидными.


# 28. Расчёт еды животного

Для каждого животного:

1. определить начало его тропинки;
2. пройти по непрерывной тропинке от животного;
3. собирать встречающиеся символы еды по порядку;
4. остановиться при достижении burrowCapacity;
5. вычислить очки каждого символа согласно foodValues животного;
6. применить waterBonus.


Пример:

capacity = 5

path food:

worm
worm
egg
egg
nut
berry

Учитываются:

worm
worm
egg
egg
nut

berry игнорируется.


# 29. Важные правила, которые легко реализовать неправильно

## Market

Нельзя автоматически добавлять новую карточку сразу после того, как игрок что-то взял.

Market обновляется только между раундами.


## Rotation

Любая карточка может быть повернута перед размещением.

Это относится и к животным, и к тропинкам.


## Dead ends

Тупики разрешены.


## Path continuation

Игрок не обязан соединять изображённую на новой карточке тропинку с соседней тропинкой.


## Branching

Разветвление одной тропинки запрещено.


## Crossing

Пересечение разных тропинок запрещено.


## Multiple animals

На одной тропинке в итоговом лесу может остаться только одно животное.


## Food limit

Количество учитываемой еды определяется вместимостью норы, а не общей длиной тропинки.


## Animal-specific scoring

Стоимость одного и того же вида еды отличается у разных животных.


## Water bonus

Жетон воды не добавляет единичное очко к общему счёту.

Он увеличивает стоимость соответствующего вида еды:

foodValue += 1

поэтому бонус применяется к каждому собранному символу этого типа.


## Burrow bonus

Жетон броненосца увеличивает вместимость:

capacity += 1

а не даёт победное очко непосредственно.


# 30. Главный игровой цикл

Игра концептуально работает так:

```
SETUP

-> fill market

-> ROUND

    -> Player 1 chooses card
    -> place card
    -> helper bonus

    -> Player 2 chooses card
    -> place card
    -> helper bonus

    -> ...

-> discard unused market cards

-> refill market

-> next round

-> repeat until forests are complete

-> resolve duplicate animals on paths

-> calculate food

-> calculate animal scores

-> add first-player-marker bonus

-> determine winner

GAME OVER
```
