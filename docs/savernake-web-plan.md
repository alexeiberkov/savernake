## 1. Краткое описание игры (высокий уровень)

Карточная игра на **2–4 игроков**: каждый собирает **свою сетку леса 4×4** (16 карт).

- Два типа карт: **тропы с едой** и **животные**.
- Общий рынок (4 слота советников): 3 path + 1 animal; в ход игрок **берёт одну** и **кладёт в свой лес**, получая эффект советника слота.
- Размещение: **смежность** (ортогональная); не выходить за **4×4**; **поворот** разрешён; тупики и «непродолжание» тропы ок; на одной тропе в итоге **не больше одного животного**.
- Цель: очки за еду по тропе каждого животного (с учётом предпочтений и лимита склада) + номинал карточки животного + бонус маркера 1-го игрока.
- Конец: у всех по 16 карт → разрешение конфликтов троп → скоринг.

**Не копировать:** дословные тексты правил, названия/тексты карт дословно из PDF, официальные иллюстрации, PDF rulebook в UI/docs.

## 2. MVP vs позже

| Область | MVP | Позже |
|--------|-----|--------|
| Лобби | Create room + **shareable link** `/r/:code`, 2–4 гостя, хост стартует | Публичный матчмейкинг, рейтинг |
| Синхрон хода | Строгий поочерёдный ход; сервер — источник истины | Таймеры, спектатор |
| Правила | Драфт + размещение 4×4 + валидация троп + советники + скоринг по спеке | 2p advanced 8×4, полировка edge cases |
| Анимация | Framer Motion: появление карт, подсветка легальных клеток, смена фазы | Богатые path-trace / score-reveal анимации |
| Контент | Плейсхолдер-арт; карты как JSON (геометрия троп, еда, вместимость) | Оригинальный арт |
| Auth | Гость + display name + resumeToken | Опционально позже |
| i18n | RU/EN переключатель на клиенте (не общий на комнату) | Другие локали |

**MVP-критерий:** 2–4 игрока по ссылке сыграют полную партию с корректной синхронизацией и объявлением победителя.

## 3. Стек (зафиксировано)

**Клиент:** React + Vite + TypeScript + **Framer Motion** (много анимации — не Phaser).  
**Сервер:** Node + Fastify (или Express) + **Socket.IO**.  
**Shared:** TypeScript types + Zod schemas + pure `GameEngine`.  
**Состояние комнат:** in-memory `Map` → Redis опционально позже.

| Слой | Выбор | Зачем |
|------|--------|--------|
| Клиент | React + Vite + TS + Framer Motion | UI сетки/драфта + плавные переходы |
| i18n | Легкий словарь / i18next | Язык **на клиента**, не на комнату |
| Валидация | Zod (shared) | Одинаковые интенты client/server |
| Realtime | Socket.IO | Rooms, reconnect |
| Деплой (позже) | Fly.io / Railway / VPS | Один процесс API+WS на старте |

## 4. Архитектура

```
[Browser React + Motion]  ←Socket.IO→  [Node Game Server]
       │                                  │
  i18n (RU|EN)                      RoomManager
  optimistic preview                GameEngine (pure TS)
  (rollback on reject)              Session / resumeToken
```

### Клиент
- Экраны: лендинг (дисклеймер) → лобби (create / join by link) → стол → итог.
- Интенты: `pickCard`, `placeCard`, `rotate`, `chooseAdvisorTarget`, `resolveConflict`, `startGame`.
- Рендер по снапшоту сервера; локальный preview размещения.

### Сервер
- `Room`: `{ id, code, players[2..4], phase, seed, state }`
- Фазы: `lobby → dealing → turn → betweenRounds → conflictResolve → scoring → finished`
- **GameEngine** — чистые функции: `(state, action) → Result<state, error>`; без I/O; юнит-тесты.

### Комнаты / сессии
- `createRoom` → код + URL `/r/:code`; `joinRoom(code)` → `playerId` + `resumeToken` (localStorage).
- Хост стартует; после старта состав фиксирован.
- Reconnect через `resume`.

### Правила на сервере
Клиент не доверяется: смежность, 4×4, рынок, порядок хода, эффекты советников, скоринг.
